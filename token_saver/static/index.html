            A LITTLE TOKEN LITERACY

            Make every token count.

            A practical guide to what Token Saver measures—and what remains an estimate.

            01

            A token isn’t a word.

            Models split text into pieces: words, parts of words, punctuation and sometimes bytes. Language, spacing, code and the model’s tokenizer all affect the count.

            Some models share a tokenizer and count identical text the same way. Their prices and generated responses can still differ.

            02

            Count input. Plan output.

            OpenAI presets use tiktoken to count supplied text. Message overhead remains an allowance. Claude, Gemini and Groq use a rough local heuristic. Optional provider counting is available for Claude and Gemini; Groq analysis stays local.

            Output and reasoning tokens are budgets you choose. Exact billed usage is only available after a model actually runs.

            03

            Platform is part of the equation.

            Presets represent the provider’s direct, standard API. ChatGPT, Claude and Gemini app subscriptions don’t translate directly into a dollar cost per prompt.

            A third-party host may add context, change prices or use a different model version. Use Custom for its rates and allow for hidden input.

            04

            Keep useful context.

            A shorter prompt isn’t automatically a better prompt. Keep constraints, examples and facts that matter. The healer proposes deterministic edits and never rewrites your prompt silently.

            For code, quotes and structured formats, automatic edits are skipped to preserve content.

            THE COST CALCULATION

            Input cost + output cost = estimated request cost

            ((uncached input × input rate) + (cached input × cache rate) + ((response + reasoning) × output rate)) / 1,000,000

            Long-context pricing is applied where configured. Cache hits must be supplied explicitly. Tool fees, media, cache writes, cache storage, taxes and hosting markups are excluded.

            Privacy & optional provider counting

            Local analysis does not send prompts to an AI provider. AI optimizer is a separate, optional cloud action: it sends your prompt and protected snippets to Groq to generate a shorter proposal when you click Optimize prompt. Set GROQ_API_KEY on the server to enable it. Tokenizer vocabularies download once and are cached. No analysis history is saved until you choose Save analysis. Saved records include the prompt and settings.

            Provider mode sends your supplied messages and system instruction to Anthropic or Google to count input tokens. Set ANTHROPIC_API_KEY or GEMINI_API_KEY in your server environment. Keys never enter the browser. No answer is generated.
